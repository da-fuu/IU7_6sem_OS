\section{Программы}
\subsection{Программа 1}
\begin{lstlisting}[caption={Исходный код Программы 1}]
#include <fcntl.h>
#include <stdio.h>

int main() {
		FILE *fs1, *fs2;
		char buff1[20], buff2[20], c;
		int flag1 = 1, flag2 = 1;
		int fd = open("alphabet.txt", O_RDONLY);
		fs1 = fdopen(fd, "r");
		setvbuf(fs1, buff1, _IOFBF, 20);
		fs2 = fdopen(fd, "r");
		setvbuf(fs2, buff2, _IOFBF, 20);
		while (flag1 == 1 || flag2 == 1) {
				flag1 = fscanf(fs1, "%c", &c);
				if (flag1 == 1)
				fprintf(stdout, "%c", c);
				flag2 = fscanf(fs2, "%c", &c);
				if (flag2 == 1)
				fprintf(stdout, "%c", c);
			}
		fprintf(stdout, "\n");
		return 0;
	}
\end{lstlisting}

\textbf{Анализ полученного результата}

Системный вызов open открывает файл alphabet.txt в режиме <<только для чтения>> (флаг O\_RDONLY), создаёт структуру file. Указатель на эту структуру помещается в таблицу файловых дескрипторов процесса fd\_array. Поскольку дескрипторы 0, 1 и 2 заняты стандартными потоками ввода-вывода, системный вызов возвращает наименьший свободный дескриптор (3), который присваивается переменной fd.

Библиотечной функции fdopen передается дескриптор fd и режим доступа <<только для чтения>>. Функция возвращает указатель на инициализированную структуру FILE (fs1, fs2), где полю \_fileno присваивается значение fd.

Функция setvbuf задаёт размер буфера 20 байт для fs1 и fs2.

Функция fscanf для fs1 сначала считывает 20 символов (<<a>>---<<t>>) из файла в буфер, при этом значение поля f\_pos структуры file увеличивается на 20. Затем из буфера извлекается первый символ (<<a>>) и записывается в переменную c, а указатель \_IO\_read\_ptr в структуре fs1 сдвигается на 1 байт. Вызов fprintf выводит этот символ в стандартный поток вывода.

Так как fs1 и fs2 ссылаются на один и тот же открытый файл, где значение f\_pos равняется 20, то при вызове fscanf для fs2 в буфер считываются оставшиеся 6 символов (<<u>>---<<z>>) из файла. Первый символ из буфера fs2 (<<u>>) записывается в переменную c и выводится в стандартный поток вывода.

В последующих итерациях цикла поочерёдно будут выводиться символы из буферов buff1 и buff2.
Когда будет достигнут конец буфера buff2, то программа продолжит выводить оставшиеся символы только из буфера buff1 (вплоть до t), пока не будет достигнут его конец.

\subsection{Программа 2}
\subsubsection{Один поток}
\begin{lstlisting}[caption={Исходный код однопоточной Программы 2}]
#include <fcntl.h>
#include <unistd.h>

int main() {
    char c;
    int flag1 = 1, flag2 = 1;
    int fd1 = open("alphabet.txt", O_RDONLY);
    int fd2 = open("alphabet.txt", O_RDONLY);
    while (flag1 == 1 && flag2 == 1) {
        flag1 = read(fd1, &c, 1);
        if (flag1 == 1) {
            write(1, &c, 1);
            flag2 = read(fd2, &c, 1);
            if (flag2 == 1)
                write(1, &c, 1);
        }
    }
    close(fd1);
    close(fd2);
    c = '\n';
    write(1, &c, 1);
    return 0;
}
\end{lstlisting}

\textbf{Анализ полученного результата}


Системный вызов open создаёт два дескриптора открытого файла в режиме <<только для чтения>> (fd1, fd2). Соответственные дескрипторам структуры file ссылаются на один и тот же inode файла <<alphabet.txt>>. Указатели на эти структуры помещаются в таблицу открытых процессом файлов под индексами 3 и 4, так как дескрипторы 0,1 и 2 заняты стандартными потоками.

Системный вызов read для дескриптора fd1 считывает один символ (<<a>>), что приводит к увеличению на 1 значения поля f\_pos в соответствующей структуре file. Считанный символ выводится в стандартный поток вывода.

Так как дескрипторам fd1 и fd2 соответствуют независимые структуры file, то для fd2 значение поля f\_pos равно 0. Поэтому при вызове read для fd2 будет считан тот же самый первый символ (<<a>>), который также выведется в стандартный поток вывода.

Поочерёдное чтение и вывод символов будут продолжаться в цикле, пока значения f\_pos в обеих структурах file не достигнут конца файла.

Таким образом, в стандартный поток вывода каждый символ алфавита будет выведен строго последовательно дважды (aabbcc...).

\subsubsection{Один основной поток и один дополнительный поток}
\begin{lstlisting}[caption={Исходный код Программы 2 с одним дополнительным потоком}]
#include <fcntl.h>
#include <unistd.h>
#include <pthread.h>

int flag1 = 1, flag2 = 1;

void* thread1_func(void* arg) {
    char c;
    int fd = *(int*)arg;
    while (flag1 == 1 && flag2 == 1) {
        flag1 = read(fd, &c, 1);
        if (flag1 == 1) {
            write(1, &c, 1);
        }
    }
    close(fd);
    return NULL;
}

int main() {
    char c;
    pthread_t t1, t2;
    int fd1 = open("alphabet.txt", O_RDONLY);
    int fd2 = open("alphabet.txt", O_RDONLY);
    pthread_create(&t1, NULL, thread1_func, &fd1);
    while (flag1 == 1 && flag2 == 1) {
        flag2 = read(fd2, &c, 1);
        if (flag2 == 1) {
            write(1, &c, 1);
        }
    }
    close(fd2);
    pthread_join(t1, NULL);
    c = '\n';
    write(1, &c, 1);
    return 0;
}
\end{lstlisting}

\jimg{2_1thread.png}{Результат выполнения программы 2 с одним дополнительным потоком}

\textbf{Анализ полученного результата}

Вызов pthread\_create создаёт дополнительный поток, которому в качестве аргумента передаётся указатель на дескриптор fd1. Поскольку на создание потока требуется время, главный поток может успеть прочитать и вывести либо весь алфавит, либо его часть.

После создания дополнительного потока чтение и вывод символов осуществляются обоими потоками в зависящей от планировщика последовательности.

Таким образом, каждый символ файла будет напечатан дважды, однако точный порядок их вывода не определён и зависит от того, как планировщик распределяет процессорное время между потоками.

int flag1 = 1, flag2 = 1;

        flag1 = read(fd, &c, 1);
        if (flag1 == 1) {
            write(1, &c, 1);
        }
    }
    close(fd);
    return NULL;
}

void* thread2_func(void* arg) {
    char c;
    int fd = *(int*)arg;
    while (flag1 == 1 && flag2 == 1) {
        flag2 = read(fd, &c, 1);
        if (flag2 == 1) {
            write(1, &c, 1);
        }
    }
    close(fd);
    return NULL;
}

int main() {
    char c = '\n';
    pthread_t t1, t2;
    int fd1 = open("alphabet.txt", O_RDONLY);
    int fd2 = open("alphabet.txt", O_RDONLY);
    pthread_create(&t1, NULL, thread1_func, &fd1);
    pthread_create(&t2, NULL, thread2_func, &fd2);

\subsection{Программа 3}
\subsubsection{Небуферизованный ввод-вывод}
\begin{lstlisting}[caption={Исходный код Программы 3 с небуферизованным вводом-выводом}]
#include <fcntl.h>
#include <unistd.h>
#include <sys/stat.h>
#include <stdio.h>

void print_stat(char *msg) {
    struct stat statbuf;
    stat("q.txt", &statbuf);
    fprintf(stdout, "%s: inode = %ld, size = %ld bytes\n", msg, statbuf.st_ino, statbuf.st_size);
}

int main() {
    int fd1 = open("q.txt", O_RDWR);
    print_stat("open fd1");
    int fd2 = open("q.txt", O_RDWR);
    print_stat("open fd2");
    for (char c = 'a'; c <= 'z'; c++) {
        if (c % 2)
            write(fd1, &c, 1);
        else
            write(fd2, &c, 1);
        print_stat("write");
    }
    close(fd1);
    print_stat("close fd1");
    close(fd2);
    print_stat("close fd2");
    return 0;
}
\end{lstlisting}

\textbf{Анализ полученного результата}

Системный вызов open создаёт два дескриптора открытого файла в режиме <<чтения и записи>> (O\_RDWR). Соответствующие дескрипторам структуры file ссылаются на один и тот же inode файла <<q.txt>>. Ссылки на эти структуры помещаются в таблицу открытых процессом файлов под индексами 3 и 4.

В первой итерации цикла системный вызов write для дескриптора fd1 записывает символ <<a>> в открытый файл, что приводит к увеличению на 1 значения поля f\_pos в соответствующей структуре file. Размер файла становится равным 1 байту.

Так как дескрипторам fd1 и fd2 соответствуют независимые структуры file, то для fd2 значение поля f\_pos остаётся равным 0. Поэтому на второй итерации цикла вызов write для fd2 заменит символ <<a>> в файле на символ <<b>>. Размер файла остаётся равным 1 байту, а значение f\_pos для fd2 увеличится на 1.

Поочерёдная запись символов в файл продолжается до конца цикла.

Таким образом, в файл будет записана только каждая вторая буква алфавита, начиная с <<b>>, и итоговый размер файла составит 13 байт, так как вызов write для fd2 будет заменять символы, записанные вызовом write для fd1.


\subsubsection{Буферизованный ввод-вывод}
\begin{lstlisting}[caption={Исходный код Программы 3 с буферизованным вводом-выводом}]
#include <fcntl.h>
#include <stdio.h>
#include <sys/stat.h>

void print_stat(char *msg) {
    struct stat statbuf;
    stat("q.txt", &statbuf);
    fprintf(stdout, "%s: inode = %ld, size = %ld bytes\n", msg, statbuf.st_ino, statbuf.st_size);
}

int main() {
    FILE *fs1 = fopen("q.txt", "w");
    print_stat("fopen fs1");
    FILE *fs2 = fopen("q.txt", "w");
    print_stat("fopen fs2");
    for (char c = 'a'; c <= 'z'; c++) {
        if (c % 2)
            fprintf(fs1, "%c", c);
        else
            fprintf(fs2, "%c", c);
        print_stat("fprintf");
    }
    fclose(fs1);
    print_stat("fclose fs1");
    fclose(fs2);
    print_stat("fclose fs2");
    return 0;
}
\end{lstlisting}

\textbf{Анализ полученного результата}

Вызов библиотечной функции fopen откроет файл <<q.txt>> в режиме <<только для записи>> ("w") и вернёт два указателя на инициализированные структуры FILE (fs1, fs2). Во время вызова создаются две независимые структуры file с дескрипторами 3 и 4, значения которых будут записаны в поля \_fileno соотвествующих структур \_IO\_FILE. Эти структуры file ссылаются на один и тот же inode файла <<q.txt>>. Для каждой структуры FILE создается свой внутренний буфер в пространстве пользователя.

Вызов библиотечной функции fprintf для fs1 записывает символ <<a>> в буфер, что приводит к смещению в соответствующей структуре указателя \_IO\_WRITE\_PTR на 1 байт.

Вызов библиотечной функции fprintf для fs2 записывает символ <<b>> в буфер, что приводит к смещению в соответствующей структуре указателя \_IO\_WRITE\_PTR на 1 байт.

В результате работы цикла в буфере fs1 будет находиться каждая вторая буква алфавита, начиная с <<a>>, а в fs2 --- каждая вторая буква алфавита, начиная с <<b>>.

Вызов fclose для fs1 приводит к записи из буфера в открытый файл. Значение поля f\_pos для дескриптора 4 и размера файла становится 13. После этого дескриптор закрывается.

Так как были созданы две структуры открытых файлов, ссылающихся на один и тот же inode, а в структуре, соответствующей fs1, значение поля f\_pos осталось равным 0, то при вызове fclose для fs1 буфер записывается в открытый файл с начала, что приводит к замене содержимого буфера fs1 на содержимое буфера fs2. Размер файла остаётся тем же (13 байт).

Таким образом, итоговое содержимое файла зависит от порядка вызовов fclose. В данном случае в файл будет записан каждый второй символ алфавита, начиная с буквы <<b>>, а размер файла составит 13 байт.
